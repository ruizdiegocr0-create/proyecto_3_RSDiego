¿De qué va este curso?

En este curso aprenderás a utilizar CSS3 para darle estilo y diseño a tus páginas web. Conocerás desde los conceptos básicos, como colores, tamaños, fuentes y márgenes, hasta herramientas que permiten crear diseños más completos y profesionales.

También aprenderás a organizar los elementos de una página, utilizar Flexbox y CSS Grid, crear diseños adaptables a diferentes dispositivos y aplicar diferentes efectos para mejorar la apariencia de tu sitio web.

Aprende los temas más importantes

Estos son algunos de los temas más importantes que debes conocer en CSS3

CSS GRID

CSS Grid permite organizar los elementos de una página web mediante filas y columnas. Es una herramienta muy útil para crear estructuras ordenadas y diseños completos de manera sencilla.

FLEXBOX

Flexbox facilita la distribución y alineación de los elementos dentro de una página. Permite crear diseños flexibles y adaptar fácilmente el contenido a diferentes tamaños de pantalla.

SELECTORES CSS

Los selectores permiten elegir los elementos HTML a los que se les aplicarán determinados estilos. Aprender a utilizarlos correctamente es fundamental para controlar el diseño de una página web.

CSS3

CSS3 permite mejorar la apariencia de los sitios web mediante colores, fuentes, fondos, animaciones, transiciones y diferentes tipos de diseño para crear páginas modernas y atractivas.

¿De qué va este curso?

Durante el curso aprenderás paso a paso cómo utilizar CSS3 para transformar una página HTML sencilla en un sitio web con un diseño atractivo. Practicarás diferentes propiedades y técnicas para mejorar la estructura, presentación y adaptación de tus páginas.
